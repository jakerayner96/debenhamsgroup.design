USP banner

The DS USP banner (Figma 11982-37171) on every core page, loaded with each fascia's live banners (06 Oct). Change the page, then each banner's colour, messages, type, copy and click-through. Everything in the frame is a design-system component.

Page

Rules

Two at most, never the same tone — one grey, one black. Adding a second banner gives it the other tone; the tone in use is disabled in its menu. No inline links — no "Shop now": the whole bar is the click-through. Height follows the copy (one line = 23px on mobile). Separator is the 4px dash. Code is always "Code: XYZ". Countdown sits on its own row. Asterisk — any * attaches the caveat line to the bottom of that banner; no caveat, no asterisk.
