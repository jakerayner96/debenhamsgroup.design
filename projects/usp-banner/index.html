Rules

Height follows the copy — one line is 23px on mobile. Separator is the 4px dash; once a row wraps it becomes a line break. Code is always “Code: XYZ”. Countdown sits on its own row. Asterisk — any * in the copy attaches the caveat line to the bottom of that banner; no caveat, no asterisk.
