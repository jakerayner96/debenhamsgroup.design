projects / P-05

PLP Alignment

status openbrief Scott · 01 Septarget w/c 08 Sepfascias 5

Align boohoo, boohooMAN, PLT, Warehouse and The Brand Room onto one core PLP template. Differences become configuration, not forks. PLT is the reference implementation.

Options

A — Strict PLT clone

All five run PLT's exact card and grid; only tokens differ.

B — PLT + toggles

PLT base; brand label, was-price, badges and grid density per fascia.

C — Density variants

B plus a compact / comfortable density switch per market.
