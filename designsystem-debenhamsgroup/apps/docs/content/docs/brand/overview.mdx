The Debenhams Group estate spans 16 facias. Each consumes this design system through a brand mode that swaps fonts, colours, and (occasionally) radius behaviour.

## Brand mode mechanics

Setting the active brand on a page is one line of HTML:

```tsx
<html data-brand="boohoo">
```

All semantic tokens resolve to that brand's values. Components don't need to know which brand they're rendering in — they just consume `bg-action`, `text-primary`, `rounded-default` etc. and the right colours, fonts, and shapes come out.

## Square radius

PLT and The Brand Room use square radius (0pt) instead of the default 4pt. This is a brand-mode choice, not a hardcoded rule — any facia can opt into square radius in future by changing one token mapping.
