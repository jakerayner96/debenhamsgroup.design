This is the design system for the Debenhams Group estate.

It powers Debenhams, Boohoo, BoohooMAN, PrettyLittleThing, Karen Millen, plus 11 other facias: Burton, Coast, Dorothy Perkins, Misspap, NastyGal, Oasis, Principles, Wallis, Warehouse, DSGN Studio, and The Brand Room.

The same components serve every brand. Brand identity is applied via theming — colours and fonts swap per brand, but the architecture, behaviour, and accessibility are identical.
