All borders, dividers, and line icons use **1pt width** by default. 2pt is reserved for focus rings and selected states where extra emphasis is required.

| Token | Value | Use |
|---|---|---|
| `border-width/default` | 1pt | Borders, dividers, icons |
| `border-width/emphasis` | 2pt | Selected states |
| `border-width/focus` | 2pt | Focus ring |

## Colour conventions

- **Grey 2** (`#e7e7e7`) — typical divider colour and PDP box borders (`border/subtle`)
- **Grey 25** (`#d6d6d6`) — standard borders around inputs, cards (`border/default`)
- **Grey 4** (`#767676`) — emphasised borders (`border/strong`)
- **Brand action colour** — focused inputs, secondary button borders, focus rings

Borders are not subject to text contrast rules, so all greys are available.
