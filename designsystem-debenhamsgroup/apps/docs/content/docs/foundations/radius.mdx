title: Radius
description: Border radius scale with brand-mode overrides
---

## Default

4pt corner radius across all components on most facias.

## Square-mode brands

PrettyLittleThing and The Brand Room use 0pt (full square) radius for everything. This is a brand-mode override — any facia can opt in.

## Scale

| Token | Value |
|---|---|
| `radius/default` | 4pt (0pt in square mode) |
| `radius/lg` | 8pt (0pt in square mode) |
| `radius/pill` | 9999px (0pt in square mode) |
