The spacing scale is based on 4pt increments. Most components use multiples of 8 for primary spacing, with 4 reserved for tight inline gaps.

## Scale

`0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128` (px)

## Common use

- `4` — Tight inline gaps (icon + label)
- `8` — Tight component padding
- `12` — Standard inline gap
- `16` — Default component padding, mobile margin
- `24` — Default desktop margin (small)
- `32` — Section breaks
- `48` — Layout-level spacing
- `96` — Desktop wide-zone side gutter (1440+)
