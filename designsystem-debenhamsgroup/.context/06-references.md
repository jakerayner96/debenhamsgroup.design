# References

Design systems, brands, and showcases used as inspiration and reference for this project.

## Tier 1 — closest to where we want to land

These are the most relevant references given the project's specific shape (multi-brand retail, code-first, brand-forward).

- **[Wise](https://wise.design/)** — gold standard for editorial polish + system rigour. Brand-led but systematised. Probably the closest aspirational reference for what debenhamsgroup.design should feel like.
- **[Polaris (Shopify)](https://polaris.shopify.com)** — best example of an ecommerce-context system with strong content alongside components. Best structural reference.
- **[Linear](https://linear.app)** — sets the bar for modern SaaS aesthetics. Confident, restrained, type-led.
- **[Mercury](https://mercury.com)** — gorgeous brand-led product design.
- **[Vercel / Geist](https://vercel.com/geist/introduction)** — clean, opinionated, beautifully documented.
- **[Stripe](https://stripe.com)** — marketing site is the reference; design system is internal but the patterns are widely studied.

## Tier 2 — proven multi-product / multi-brand systems

Strong on scale and structure.

- **[Carbon (IBM)](https://carbondesignsystem.com)** — multi-product enterprise system done well
- **[Atlassian Design](https://atlassian.design)** — multi-product, lots of product context
- **[Primer (GitHub)](https://primer.style)** — code-first, well-documented
- **[Lightning (Salesforce)](https://www.lightningdesignsystem.com)** — at scale
- **[Spectrum (Adobe)](https://spectrum.adobe.com)** — for cross-platform thinking

## Tier 3 — guidelines / foundational

For broad design language ideas, not direct structural reference.

- **[Material Design 3](https://m3.material.io)** — token system thinking, motion
- **[Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines)** — for app components if Debenhams Group apps are ever in scope
- **[Fluent (Microsoft)](https://fluent2.microsoft.design)** — tokens and theming
- **[GOV.UK Design System](https://design-system.service.gov.uk)** — accessibility and clarity exemplar
- **[USWDS](https://designsystem.digital.gov)** — government, principled

## Tier 4 — open source / developer-flavoured

Useful for technical patterns but visually too generic for our needs.

- **[Radix UI](https://www.radix-ui.com)** — primitives, accessibility done right
- **[shadcn/ui](https://ui.shadcn.com)** — popular, themable
- **[Base Web (Uber)](https://baseweb.design)**
- **[Ant Design](https://ant.design)** — large component coverage

## Tier 5 — brand expression references

Less for design system structure, more for the brand-presence pages within the system. Useful for the per-brand pages on debenhamsgroup.design that introduce each fascia.

- **[Porsche](https://designsystem.porsche.com)** — brand-led system with bold expression
- **[Audi UI](https://www.audi.com/ci)** — tightly controlled
- **[Mercedes-Benz](https://www.mercedes-benz.com/en/design)** — premium tone
- **Range Rover / JLR** — strong digital brand work, less publicly documented
- **[Polestar](https://www.polestar.com)** — minimal, automotive
- **[Rivian](https://rivian.com)** — bold, modern
- **[Koto Studio](https://koto.studio)** — agency client work (Pleo, Robinhood, Amazon Music) — for the kind of brand thinking that should sit alongside the system

## Mental model

When designing or making decisions:

- **Wise / Polaris** for structure and information architecture
- **Mercury / Linear / Vercel** for visual baseline (modern, confident, type-led)
- **Porsche / Audi** for the brand-expression pages within the system
- **Carbon / Atlassian / Primer** for evidence of how to scale (multi-product, multi-brand patterns)

The aspirational sentence: "debenhamsgroup.design should look and feel like Wise's design system, structurally, with brand-expression pages that have the confidence of Porsche's, presenting components that have the polish of Linear's product."
