## Gotchas
- html2canvas takes the clone's base URL from the **calling script's document**: calling it from the shell on an embedded page broke every relative URL (unstyled live PDP, no PLP images). Capture via `iw.Function(...)` + the page's own `setTimeout`, and read the canvas bytes before removing the frame (a canvas from a removed document never calls `toBlob` back).
- The embedded pages re-render on resize → fresh `loading=lazy` images that never load off-screen; the export loop re-marks them eager until all are complete.
- The live PDPs set the fascia font on a container, not `<body>` — the pinned toast copies the gallery's font.
