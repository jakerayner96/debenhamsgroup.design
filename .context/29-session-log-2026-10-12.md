## Fixes worth remembering
- `classList.toggle(cls, a&&b || c&&d)` can return `undefined`, which **flips** the class instead of forcing it. Always coerce to a boolean.
- html2canvas 1.4.1: `color-mix()` throws (Deliver+ `.dplus .foot`). Text vanishes in an `inline-flex` button inside a flex container (use `display:flex`). Gradient `url(#id)` fills drop.
- plp-alignment `data.js` Debenhams: product i → `p{i}.jpg` for i < 7, `p{i+1}.jpg` after that.
