## Decisions (Jake)
- **Pages use what's live**, not DS page components: Home = each fascia's live homepage (images + live text overlays, `home.js`, `img/home/<brand>/`); PLP = the P-05 prototype embedded (`plp.html?mode=new`); PDP = Core PDP 2026 embedded (`../core-pdp-2026/pdp.html`, sibling Pages repo, same origin; boohooMAN build on every fascia); Bag = live `/basket` payment summary (`bag.js`). - **Rows**: at most two; row 1 usually rotates, row 2 fixed; one row on boohoo, KM, Warehouse, Brand Room; PLT is the reverse (peach countdown fixed, cream rotates). Each row keeps the fascia's live colour, copy casing and font on DS styling. Content re-captured 07 Oct (`live.js`).
- **No jump**: a rotating row holds its tallest message's height (`.usp-stack`); desktop lays the messages across the bar (`.usp-cells`, Debenhams + PLT alternate cell shades as live).
- **Rotation**: 5s, smooth crossfade — incoming fades in over the solid outgoing message, no background flash.
- **Caveat copy**: no em dashes, no full stop. Prototype has a Caveats on/off toggle (strips asterisks + caveat lines) for with/without comparisons.
- Spacing question (constant top/bottom padding vs fixed-height rotating rows when messages differ in line count) was raised and not answered — current: fixed row height, message centred.
