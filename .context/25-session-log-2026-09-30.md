## What changed — the chrome (all CSS in the `<head>` `<style>` block)

- **Type.** Archivo Black uppercase display + Google Sans body → **Geist** (300–800) for everything and **Geist Mono** for labels, kickers, ids, table heads. h1s are 40px/600, tracking −.035em, sentence case, with a white→72% white gradient fill (Linear). Body 14px, letter-spacing −.006em, `ss01`/`cv11` features. Brand fonts (Geologica, Montserrat, Roboto, Jost) still load for the DS demos; `--font-family-base` inside every canvas is unchanged.
- **Surfaces.** `#000` → `#08090A` with `--panel` `#0C0D0F`; hairlines at 7% / 13% / 22% white; every card is a `--card` gradient (2.8% → 0.8% white) + `--hi` 1px inset top highlight; radii 12/16. Tables and token lists lost their solid header fills.
- **Status.** Boxed uppercase pills → **dot + word** pills (Vercel): green = live/merged, amber = open/wip, grey = queued. Sidebar tags are dot + word with no border. Dev-alignment `.dv` chips follow the same pattern.
- **Sidebar.** 320–420px Finder panel → 264px, same background as the page, hairline right edge, mono group labels, filled pill for the active item (no aqua left bar), quieter icons.

- **Motion.** Page enter (8px rise + fade, 360ms), card hovers (2px lift + soft shadow), arrow nudges, fascia marquee (60s loop, pauses on hover), eyebrow pulse. All collapse under `prefers-reduced-motion`.
- **Search palette.** Frosted, 14px radius, same enter animation.

## Addendum 7 — square PLT / Brand Room, softer canvases, spinners hold their width

- **Radius follows the brand everywhere.** `components.css` had 40-odd literal radii (4px, 3px, 8px, 22/25/42/100px pills). They now read the tokens: 4px → `var(--radius-default)`, 3px → `calc(var(--radius-default)*.75)`, 6px → ×1.5, 8px → `var(--radius-lg)`, pills → `var(--radius-pill)`. PLT and The Brand Room set all three to 0, so buttons, fields, cards, chips, filter pills, tag pills, sheets, modals, badges, the Pay CTA and the new-format sort & filter pills (`.sf-pill`, previously a fixed 42px per the Brand Room Figma) are square there. Deliberately still round: spinner ring, radio, toggle, count roundel, threshold tick, dots, payment scheme chips.
- **Spinner buttons keep their width.** `.bd.spn` is an inline grid; the label (`<span class="lbl">`) and the arc share one cell, label `visibility:hidden`, so the button is exactly as wide as its labelled state. Catalogue spinner variants carry the label (Buy it now / Add to bag / Continue shopping / Tertiary / Tertiary XS); Storybook regenerated.
- **Less contrast.** Light theme base is `#F0F0F2` (white-leaning grey). Demo surfaces in the chrome (`.canvas`, `.ctile .cv`, `.fx`) are the fascia's `--surface-page` mixed 6% towards black, so pure-white pages show as `#F0F0F0` while tinted pages (PLT cream) keep their tint. `components.css` itself is untouched by this, so prototypes still render true page colours.
- `dgLum()` replaces the old rgb-only luminance parse; `color-mix()` computes to `color(srgb …)`, which the old regex misread and flagged every box dark.
