## The operating model (locked)

- **One repo, branches as briefs.** `main` = the master site prototype (canonical core pages built from DS components). New brief → branch → 2–4 options built as variants → stakeholder review on the branch URL → chosen option merges to main → branch archived as the project record.
- **OptionSwitcher** — a reusable overlay (FAB/dock) to flick between options on a review URL. The GDS repo's brand dock is the interaction prototype for it. Build once, reuse on every brief.
- **The site is the front door**: System (docs + live components), Projects (file browser/wiki — options + chosen route per brief), Brand Centre (per-fascia guidelines), Requests (status view over the existing UX-Design-Request worker — no new ticketing system).
- **Master prototypes** are first-class: M-01 PLP (building), M-02 PDP, M-03 Bag, M-04 Checkout, M-05 Home (queued). Briefs branch from these; winners merge back.
