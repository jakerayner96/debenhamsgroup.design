Ecom team → creative team. Fill in every field, add one reference for each screen, then export the PDF and send it to creative. They will capture exactly what you reference for each screen.

Sets needed

Which fictional account to log in with, what should be in the basket / wishlist / orders, any settings (dark mode, location)

2 · Screens

In order: screens 1–3 matter most. For every screen give ONE reference: a screenshot from the previous build showing exactly how it should look, OR a link to the equivalent page on the website (a specific PLP, PDP or content page) with the scroll position and any filters or selections. Max one brand panel per set, never in positions 1–3.
