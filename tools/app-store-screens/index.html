Start the runner on your Mac

This page drives the iPhone/iPad Simulator and Android emulator on your Mac through a small local runner. Install it once (needs Xcode, Android Studio and Node.js); it then starts by itself at login. Use Chrome.

curl -fsSL https://jakerayner96.github.io/debenhamsgroup.design/tools/app-store-screens/runner/install.sh | bash

Already installed and stopped? launchctl load ~/Library/LaunchAgents/com.debenhamsgroup.appstorescreens.plist

Screens to capture

The brand team sends screenshots of the screens they want, in order. Drop them here: each becomes a screen. Learn has Claude find the way to it in the app once; after that the route replays on every device and language. Known screens (Home, Wishlist, Bag…) can use a built-in route instead.

Setup check
    
      
    Claude API key
    Needed only for Learn (finding the route to a new screen). Stored in this Mac's Keychain. Uses Claude Opus 5.5, a few pence per screen learned.
    
        
    
        
    Update the runner
    Run the install command again to pick up the latest version.
    curl -fsSL https://jakerayner96.github.io/debenhamsgroup.design/tools/app-store-screens/runner/install.sh | bash
    
    
    
    
    How the brands ask for screens
    
      
    Ask each brand to screenshot the live app on their phone, one screenshot per screen they want in the listing, numbered in order (01-home.png, 02-wishlist.png…), plus anything that must show (products in the bag, a campaign). Drop them into Screens, press Learn on each, then Test. From then on every new build is one paste and one Export.
