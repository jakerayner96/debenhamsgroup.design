# debenhamsgroup.design

The Debenhams Group UX site — design system, project archive, brand centre and request board. Dark, sidebar-driven, single file, no build step.

- `index.html` — the site (v3 wireframe). Open in a browser or serve the folder.
- `explorations/` — the design directions explored to get here (A precision, B editorial, C monolith, D index, plus v1 and v2).

## Hosting

GitHub Pages: repo Settings → Pages → Deploy from branch → `main` / root.
Live at `https://jakerayner96.github.io/debenhamsgroup.design/`

## Provenance

Demo brand tokens are lifted from `Group-Design-System/css/tokens.css`, itself generated from `plt-app-prototype/src/theme/brands.ts`, itself lifted from the DS Figma. Code first; Figma downstream.
